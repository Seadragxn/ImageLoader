# Image Loader 0.5.x (legacy)

This branch preserves the final 0.5-series source for Image Loader, a tModLoader mod that loads PNG/JPEG URLs and places them as vanilla or Exact RGB blocks.

The current stable release and full documentation live on the `main` branch. Use this branch only when maintaining a 0.5.x installation or comparing behavior with version 0.6.0.

## Controls

- `P`: open Image Loader
- `G`: toggle Gallery Mode
- `Ctrl` + mouse wheel or `Page Up` / `Page Down`: Gallery zoom
- `/imageloader`: open the menu from chat

## Building

Copy this checkout to the tModLoader `ModSources\ImageLoader` directory, then use **Workshop → Develop Mods → Build + Reload**.
